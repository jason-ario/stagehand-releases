# Stagehand — Downloads

Official builds of Stagehand for macOS and Windows.

**[Download the latest release →](https://github.com/jason-ario/stagehand-releases/releases/latest)**

| Platform | File |
|---|---|
| macOS (Apple Silicon & Intel) | `Stagehand-macOS.zip` |
| Windows 10/11 (64-bit) | `Stagehand-Windows.zip` |

### First launch
- **macOS:** unzip, drag Stagehand to Applications. Until builds are notarized, right-click → **Open** the first time.
- **Windows:** unzip and run `Stagehand.exe`. If SmartScreen appears, choose **More info → Run anyway**.

Each release includes `SHA256SUMS.txt` to verify downloads.

This repository holds release binaries only; the source lives in a private repo.
